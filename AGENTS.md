# Техническое задание: Модуль «Статьи и комментарии» (MVP)

## 1. Дизайн и UX
- **Источник дизайна:** Списать верстку и стили строго с [https://narrative-eight-blue.vercel.app/](https://narrative-eight-blue.vercel.app/), используя за основу **вкладку «Все статьи»**.
- **Каталог:** На старте открывается каталог реальных статей из базы данных. Никаких хардкоренных фейковых/рыбных статей на фронтенде быть не должно (если в базе пусто — каталог пустой).

## 2. Структура Базы Данных (с учетом вложенности)
- **`blog_topic` (Статьи):**
  - `id_blog_topic` — идентификатор статьи
  - `name` — название/заголовок
  - `value` — текст статьи
  - `id_user` — автор (связь с `users`)
  - `create_datetime` — дата публикации
- **`blog_post` (Комментарии с поддержкой вложенности):**
  - `id_blog_post` — идентификатор комментария
  - `id_blog_topic` — внешний ключ к статье
  - `parent_id` (или аналог) — указатель на родительский комментарий (для корневых — `NULL` / `0`)
  - `id_user` — автор комментария
  - `value` — текст комментария
  - `create_datetime` — дата публикации

## 3. Серверная логика (диспетчер действий в `script_template.php`)
Реализовать через штатный API-диспетчер следующие методы:
- `getBlogTopics` — список всех статей с данными авторов.
- `getBlogTopicById` — детальная страница конкретной статьи.
- `getBlogPosts` — список комментариев к статье (`id_blog_topic`), с поддержкой иерархии (вложенности) и сортировкой.
- `addBlogPost` — добавление комментария (или ответа на комментарий) авторизованным пользователем (`$context['u_id'] > 0`).
- `editBlogPost` — редактирование комментария:
  - Проверка авторства (`id_user === $context['u_id']`).
  - Проверка условия: комментарий является **последним в своей ветке** (последним по времени/ID в данном древе ответов).
- `deleteBlogPost` — удаление комментария с аналогичной проверкой авторства и условием крайнего комментария в ветке.

## 4. Клиентская часть (React / TypeScript)
- Компонент каталога и детального просмотра статьи (`blog_topic`).
- Компонент древовидных вложенных комментариев (`blog_post`) с формой отправки/ответа.
- Кнопки действий («Редактировать» / «Удалить») отображаются **строго на крайнем комментарии текущего пользователя в его ветке**.
- Реализовать инлайн-редактирование и подтверждение удаления.
