# Repair Wizards Regression Pack v1.3

Три ZIP-архива и распакованные исходники для проверки формата статей 1.3.

- `smartphone.zip` — смартфон, блок model_3d и полный набор technical_knowledge.
- `electric_kettle.zip` — электрочайник, галерея и безопасные границы диагностики сетевого прибора.
- `toilet_cistern.zip` — механический бытовой объект, галерея и пошаговая замена сливного механизма.

См. [COVERAGE_MATRIX.md](COVERAGE_MATRIX.md). Материалы демонстрационные; схемы SVG не являются фотографиями. Видеоссылка тестовая.
