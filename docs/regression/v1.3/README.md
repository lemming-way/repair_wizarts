# Repair Wizards Regression Pack v1.3

Регрессионный набор проверяет только формат статей v1.3 и связанный код импорта, валидации, хранения/выдачи JSON и отображения. Он не является тестовым набором всего приложения.

## Демонстрационные ZIP-статьи

- `smartphone.zip` — смартфон, блок `model_3d` и полный набор `technical_knowledge`.
- `electric_kettle.zip` — электрочайник, галерея и диагностика сетевого прибора.
- `toilet_cistern.zip` — механический бытовой объект, галерея и пошаговая замена сливного механизма.

Все 12 типов блоков представлены в совокупности трёх статей. Не требуется включать каждый тип в каждую статью.

## Состав регрессионного набора

- 12 типов блоков: `heading`, `paragraph`, `image`, `gallery`, `video`, `list`, `quote`, `callout`, `steps`, `table`, `code`, `model_3d`.
- Позитивные и негативные проверки JSON и обязательных полей.
- ZIP-структура, методы Store/Deflate, целостность файлов и повторный импорт.
- Проверка реестра `assets`, ссылок на файлы и `size_bytes`.
- Сохранение полного JSON и необязательного `technical_knowledge`.
- Preview и опубликованная статья через единый `ArticleRenderer`.
- Безопасный вывод текста, проверка ссылок и изоляция ошибок отдельных блоков.
- Мобильное отображение галереи, таблиц, шагов и длинного кода.

Подробная матрица сценариев и ожидаемых результатов: [COVERAGE_MATRIX.md](COVERAGE_MATRIX.md).

## Границы

Не тестируются общие подсистемы приложения (заказы, платежи, чаты, авторизация и т. п.) и общий coverage проекта. ZIP Slip, decompression bomb, MIME-sniffing и дополнительные ZIP security controls относятся ко второму этапу. ZIP Data Descriptor поддерживается импортёром: signed/unsigned descriptor и проверка CRC32.

## Демонстрационные ограничения

SVG-файлы — авторские схематические иллюстрации, не фотографии. GLB — упрощённая демонстрационная геометрия корпуса смартфона, не модель конкретного устройства. Видеоссылка тестовая. Демоматериалы не следует публиковать как проверенные ремонтные инструкции.
